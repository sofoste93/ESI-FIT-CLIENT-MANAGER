# Changelog

## 2.0.0 — Console Orbit — 2026-10-01

- Rebuilt the numbered menu as a full-screen, keyboard-first terminal interface.
- Added dashboard metrics, member search and management, live attendance and visit history.
- Replaced fragile text persistence with a local H2 database.
- Added automatic migration from the original `clients.txt` and `sessions.txt` files.
- Added CSV attendance exports and a built-in help panel.
- Added native, self-contained packages for Windows, Linux and macOS.
- Added automated tests, runtime diagnostics and a multi-platform GitHub release pipeline.
- Added optional Authenticode signing for the Windows installer.
